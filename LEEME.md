# Yalan Horror (Forge 1.20.1) - sin dependencias

Necesita SOLO: Minecraft 1.20.1 + Forge 47.x (no necesita GeckoLib ni nada más).

## Compilar el .jar (sin instalar nada) - GitHub Actions
1. Crea un repositorio en github.com (privado sirve) y sube TODO el contenido de esta carpeta.
2. Pestaña "Actions" -> "build-mod" -> espera ~5 min -> descarga el artefacto "yalanmod-jar".
3. Descomprímelo: el archivo `yalanmod-1.0.0.jar` va en la carpeta `mods` de tu TLauncher (perfil Forge 1.20.1).

## Compilar en tu PC
Java 17 + Gradle 8.1.1:  `gradle build`  -> `build/libs/yalanmod-1.0.0.jar`

## Comandos (necesitan cheats / OP)
/yalan evento     apagón + frases + aparece Yalan a 22-32 bloques
/yalan aparecer   aparece directo
/yalan screamer   prueba el screamer
